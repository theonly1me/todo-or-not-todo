# Project instructions

Read the relevant Next.js guide in `node_modules/next/dist/docs/` before changing framework integration.

Keep files under 200 lines. Use strict TypeScript without casts, `any`, non-null assertions, or code comments.

Run `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build` before presenting changes.

Never commit environment files, credentials, or generated build output. Ask for review before committing or pushing.
